# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

We welcome contributions that improve the code, documentation, usability, and reliability of this project.

## How to Contribute

### 1. Fork the Repository

Fork this repository to your own GitHub account.

### 2. Clone Your Fork

Clone your fork to your local machine:

```bash
git clone https://github.com/raptoradassault/simple-interest-calculator.git
cd simple-interest-calculator
```

### 3. Create a Branch

Create a descriptive branch for your changes:

```bash
git checkout -b feature/your-change
```

### 4. Make Your Changes

Make your changes while keeping the code simple, readable, and maintainable.

For code changes, verify that the script works with valid numeric inputs and produces the expected simple interest.

### 5. Test Your Changes

Run the script:

```bash
bash simple-interest.sh
```

Check that the calculated result is correct.

### 6. Commit Your Changes

Use a clear, descriptive commit message:

```bash
git add .
git commit -m "Describe your changes"
```

### 7. Push Your Branch

Push your branch to your fork:

```bash
git push origin feature/your-change
```

### 8. Open a Pull Request

Open a pull request against the original repository's `main` branch.

Explain what you changed, why you changed it, and how you tested it.

## Contribution Standards

- Write clear, readable code.
- Keep changes focused on a specific improvement.
- Use descriptive commit messages.
- Update documentation when necessary.
- Test changes before submitting a pull request.
- Be respectful and constructive when communicating with other contributors.
- Follow the project's Code of Conduct.

## Reporting Issues

When reporting a bug, describe the problem, steps to reproduce it, expected behavior, and actual behavior.
